# V14.3.1 — Diagnóstico de acciones de evento
Esta versión añade mensajes visibles de progreso y errores, verifica el estado tras cada acción y fuerza la actualización del JavaScript en GitHub Pages.
## Instalar
Sustituye `index.html` y `js/admin.js` en GitHub. Mantén el resto de archivos y la configuración. Recarga con Ctrl+F5.
La migración `database/v14_3_migration.sql` de la V14.3 debe estar aplicada en Supabase; no hace falta volver a ejecutarla si ya se ejecutó correctamente.
Si aparece un mensaje de error, cópialo exactamente. No se ha probado contra tu instancia de Supabase.
