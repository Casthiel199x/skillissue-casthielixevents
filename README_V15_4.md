# SKILL ISSUE V15.4 — Identidad global

Estilo Adventurer Archive aplicado a administración, espectadores y votaciones.

## Instalación
Subir el contenido del ZIP a la raíz del repositorio de GitHub Pages, respetando carpetas. Conservar la configuración `skill_issue_config.js` propia de tu proyecto. Recargar con Ctrl+F5.

## Alcance
Cambio de estilos CSS globales y parámetro de versión en los tres HTML para reducir caché. Sin cambios a JS, RPC, base de datos, Supabase ni reglas de puntuación.

## Nota
La comprobación de funcionamiento final debe hacerse en el sitio publicado.
