# SKILL ISSUE V15.2 — Adventurer Plates

Rediseño visual de la ficha pública de participantes: estilo FFXIV + SKILL ISSUE.

## Instalación
Sube el contenido de este ZIP a la raíz del mismo repositorio GitHub Pages, reemplazando los archivos existentes. Conserva `skill_issue_config.js` con tu configuración actual (no lo sustituyas si contiene tus claves públicas y URL). No requiere SQL ni cambios en Edge Functions.

## Cambios
- Ficha con retrato grande, marco ornamental, nombre, mundo, job y raza.
- Clasificación, puntos, eventos, victorias y podios.
- Distinción visual para los tres primeros puestos.
- Responsive móvil, enlace Lodestone, estado sin retrato.
- No cambia RPC, administración ni sistema de puntuación.

Nota: los datos faltantes dependen de la importación desde Lodestone.
